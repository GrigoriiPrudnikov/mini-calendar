# Mini Calendar
Mini Calendar is Telegram Mini App, built with React

## Run locally
1. Clone this repository

`git clone https://github.com/GrigoriiPrudnikov/mini-calendar.git`

2. Install dependencies
```bash
# npm
npm install
# pnpm
pnpm install
# yarn
yarn install
```

3. Run localhost
```bash
# npm
npm run dev
# pnpm
pnpm run dev
# yarn
yarn run dev
```

3. Install and run [Tuna](https://tuna.am/)
Tuna is used to test app in Telegram without creating developer environment. It mirrors localhost to https server.

You need to [create free account](https://my.tuna.am/sign_in) and follow [installation guide](Быстрый старт | Tuna Документация)
 
After install run this command while localhost is running. This will create a mirror of your localhost.

`tuna http localhost:5173`
\*5173 is port vite use by default.
